
# 🎓 C++ Based Academic Management System

A console-based Academic Management System developed using C++ as part of the **Software Development Project-I (SDP-I)** course.

The project aims to simplify and organize academic management activities by providing a structured system for managing student information, faculty details, course information, and academic results.

## 📌 About the Project

The Academic Management System is designed to demonstrate the practical application of C++ programming concepts in developing a real-world academic management solution.

It brings different academic information and management operations together in one console-based application.

This project was developed as part of the Software Development Project-I coursework.

## ✨ Features

- **Student Management:** Store and manage student-related information.
- **Faculty Information:** Maintain faculty details.
- **Course Management:** Manage academic course information.
- **CGPA Management:** Handle student CGPA-related information.
- **Academic Results:** Store and manage academic results.
- **File Handling:** Use text files to store and retrieve information.
- **Console-Based Interface:** Perform operations through a command-line interface.

## 🛠️ Technologies Used

- **C++** – Core programming language.
- **File Handling** – For storing and retrieving academic data.
- **Object-Oriented Programming (OOP)** – For organizing program structure.
- **Standard Template Library (STL)** – Where applicable.

## 🚀 Getting Started

Follow these steps to run the project on your local machine.

### 1. Clone the Repository

```bash
git clone https://github.com/arghoghosh88/SDP-I.git
```

### 2. Navigate to the Project Directory

```bash
cd SDP-I
```

### 3. Compile the C++ Program

Using the GNU C++ compiler:

```bash
g++ SDP_Final_Project.cpp -o SDP_Project
```

### 4. Run the Program

**Windows:**

```bash
SDP_Project.exe
```

**Linux / macOS:**

```bash
./SDP_Project
```

> Note: Make sure to compile the intended final project source file. The repository contains multiple C++ source files for development and testing.
